# fire26-sdai

Static website for the FIRE 2026 special session on Sustainable Development through AI.

## Pages

- `index.html` — overview and key dates
- `theme.html` — background and purpose of the session
- `submissions.html` — eligibility and proposal checklist
- `evaluation.html` — review criteria and technology requirements
- `session.html` — timeline, programme, and prize information

The site uses plain HTML and a shared `styles.css`, so it can be opened directly in a browser while the content and visual details are refined.
